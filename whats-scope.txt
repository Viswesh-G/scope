The project: Scope — a self-profiling search engine
The idea: build ripgrep-lite in Go (fast regex search over files/streams), then instrument it with your own Prometheus-style metrics layer, and finally build a flamegraph-annotated web dashboard that shows you exactly where time is going — per query, per file type, per goroutine.
The recruiter story: "I built a fast grep from scratch, wrote my own metrics collection layer, and built a live performance dashboard on top of it. Every query generates a flamegraph. I used this to find and fix a 4x bottleneck in my regex compilation path."

The two original ideas had a hidden tension — minigrep teaches you how things are slow, Oberv teaches you how to see things being slow. Scope merges them: you're building the tool, and simultaneously building the instrumentation to understand the tool. That recursive loop (the search engine observing itself) is exactly what production systems like Jaeger, Pyroscope, and Grafana Tempo are built on.
A few things that make this standout on a resume: the flamegraph isn't borrowed from a third-party tool — it's generated by your own pprof wrapper, from profiles of your own searches, rendered as SVG by your own code. The entire pipeline is yours. Second, the final binary ships as a single Docker container with a browser UI embedded in it. You docker run it in an interview and the recruiter sees live charts and flamegraphs updating in real time. That's not a README screenshot — that's a live demo.
